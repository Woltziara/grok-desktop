## 单元一：取消恢复与精确原话来源

- 普通明确的 prompt RPC 失败不再把整个连接当作已取消；限流、认证和服务错误之后，反向请求与下一次 prompt 仍可使用同一连接。
- 隔离旧 transport 与隐藏 session/load 回放分开。新连接可接收 folder trust 和 MCP elicitation；旧 reader 不能污染新连接。
- 恢复加载失败保留原会话 id；下一次重试重新启动连接。恢复中再次取消不会被完成回调抹掉。
- 指定 inboxIds 时先按事件 id 限定来源，再匹配原话；不会以同文第一条替代第二条或另一个会话来源。不明确指定的旧单输入格式仅回落 ctx.inboxId，不扩大搜索。
