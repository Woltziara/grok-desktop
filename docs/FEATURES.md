# 统一版本的功能与继续事项

产品方向只由 [INTENT-LOCK.md](INTENT-LOCK.md) 维护。这里记录统一主线的行为与交付边界，不把旧会话的自报当作验收。

## 本次收成一套实现

| 能力 | 统一后的行为 |
| --- | --- |
| 会话与草稿 | 项目/最近列表、项目内新建、后台回合保留；草稿、图片、文件夹附件和引用按会话恢复 |
| 消息与阅读 | 历史与实时尾部合并；插话按身份去重；阅读锚点不被中途插话重置 |
| 插话与队列 | Enter 插入当前回合、稍后 FIFO、Cmd/Ctrl+Enter 取消后发送；只用一套 ACP 协议和 UI 路由 |
| 计划与授权 | session/set_mode、计划审批、问题与文件夹信任由主进程保管，界面重载可恢复 |
| 工作认识 | 业务对象明确选择；未指定原文直通；用户纠正与撤回可见；普通原话和机器背景分离；无内置业务种子或自动探针 |
| Preview | 自有持久分区、Playwright 结构化控制、保留必要 DOM fallback、明确窗口归属、安全创建/关闭 |
| 僚机 | 同一应用包可独立发送；本软件源码退出文件时间覆盖；会话资料与登录操作分别展示范围 |
| 打包 | 一份 manifest/lock/source 经 electron-builder 完整生成；检查真实依赖、Helper 与 ASAR 完整性 |

## 继续事项

- **网页 Pro 到本机开发的完整闭环**：桌面通过本应用 Preview 归属打开真实 ChatGPT，并记下交办。隔离 Preview 已碰到登录墙；没有本人登录，不能声称真实 Pro 已验收。不要用其他浏览器 Cookie 顶替。
- **真实账号登录保持**：持久分区可以用可控样例验证；ChatGPT 首次登录以及账号状态跨重启仍需本人账号现场验证。
- **原生记忆与工作认识的边界**：原生 Grok memory 负责通用会话记忆；结构化对象、纠正和撤回保留为可关闭扩展。未验证当前运行版本的 memory v2 全链路前，不迁移现有数据。
- **两台机器接着做**：选定会话/资料接续包、工作认识独立入口、当前候选包导出。旧整机时间覆盖和登录搬运保持停用。不能用文件时间裁决哪条业务判断正确。
- **其他平台**：本次部署目标为 macOS Apple Silicon；Windows/Linux 的行为只能按对应实际测试报告声明。

## 维护原则

优先复用 Grok Build 的 agent、会话、技能、MCP、权限和工作树，以及 Electron/Playwright 的浏览器能力。桌面只增加人看见与操控工作所需的适配；新增流程必须能通过真实任务改善结果，不能只增加文件和工具名称。
