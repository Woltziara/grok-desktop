# Contributing

This GUI is MIT. Please keep `LICENSE` and `NOTICE.md` intact.

- Do not vendor AGPL code (Cherry Studio, opcode, and similar).
- Do not copy Codex / Claude / ChatGPT assets. Behavior references only.
- Grok Build itself lives in [xai-org/grok-build](https://github.com/xai-org/grok-build). Do not vendor that tree here.
- Fonts (仓耳今楷, Hack, etc.) are not redistributed; do not add font files unless their licenses allow it and `NOTICE.md` is updated.

Issues and pull requests: use this GitHub repository.
